# exp08：Qwen3.8-27B 的 5bit 与 6bit——32/48 GB 档上"上下文换量化损失"的中间点

日期 2026-09-22。m3u。`lmk pull` HF 当前版本（lmstudio-community 的 5bit / 6bit）。同家族同模板，零代码。

## 预期（跑之前写）
1. 集成测试关/开 **5/5 ×2** 各。把握：高。
2. 装载后：5bit 约 18.5 GiB，6bit 约 22 GiB（按 4bit 14.95 与 8bit 27.48 线性内插）。分组：5bit **32 GB**（该机型约 60k），6bit **36 或 48 GB**。把握：中。
3. decode 受带宽限制，∝ 1/权重字节：5bit **约 32**，6bit **约 28** tok/s（4bit 39.5、8bit 23.1 之间）。prefill 都 ≈320。把握：中高。
4. agent 任务三轮缺省采样：全对（4bit/8bit 都是）。把握：高。
5. 质量差异不量（没有评测）。
