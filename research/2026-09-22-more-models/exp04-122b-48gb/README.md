# exp04：baa-ai/Qwen3.5-122B-A10B-RAM-48GB-MLX——122B 能不能上小内存 Mac

日期 2026-09-22。m3u（M3 Ultra 96GB），权重 44 GB，`~/.lmstudio/models/baa-ai/Qwen3.5-122B-A10B-RAM-48GB-MLX`（HF sha d06d744）。
常驻（122B 标准版）测试期间停掉。

## 先查到的
量化方案（config.json `quantization`）：**路由专家 2 bit（113 个张量）/ 3 bit（31 个）**；注意力与线性注意力 4–8 bit（多为 6/8）；
共享专家 5–8 bit。即"省的内存全部来自把专家压到 2–3 bit"。HF 下载 484、赞 11（标准版是主流仓库）。

## 预期（跑之前写）
1. **加载**：baseline 约 41 GiB ⇒ 窗口**保住 262,144**。把握：高。
2. **集成测试**（思考开、关各一遍）：格式与模板同标准版 ⇒ 5/5 两次。把握：中——2 bit 专家可能让工具调用参数出错（类型/路径）。
3. **decode**：每 token 读的字节更少（专家 2–3 bit）⇒ **比标准版快**，70–90 tok/s。把握：中。
4. **prefill**：算力受限 ⇒ 与标准版持平，约 750。把握：中。
5. **质量**：exp03 的三个 agent 任务（思考关）至少 2/3 对；250 词故事关思考能完成。把握：低——2 bit 专家的损伤没人量过。

## 结果（2026-09-22，raw/）
| | 预期 | 实得 |
|---|---|---|
| 加载 | 窗口保住 262k | 25 s；baseline 43.9 GiB；**262,144 保住** ✓ |
| 集成测试 | 5/5 ×2 | **思考开 5/5（140 s）、思考关 5/5（99 s）** ✓ |
| decode | 70–90（字节更少） | **53.7 tok/s——比标准版的 60.5 慢** ✗ |
| prefill | ≈750 | 746 ✓ |
| cached prefill | — | 89k |
| 三个 agent 任务（思考关） | ≥2/3 | **3/3**，每步 20–57 token ✓ |
| 250 词故事（思考关） | 完成 | 362 token，289 词，完成 ✓ |

decode 猜错了方向：专家压到 2–3 bit 字节是少了，但速度反而慢 11%。推测是 2/3 bit 的解量化 kernel 不如 4 bit 的快、
且混合位宽让每层走不同路径——**推测，没有单独量**。结论：这个版本换到的是内存（窗口 262k 对 165k、并发预算翻倍），不是速度。
质量：四个小任务与标准版逐字几乎相同（故事开头同一句），但这不是质量评测；2 bit 专家在难任务上的损伤仍未知。
