## 预期（跑之前写）
1. **math**：122B-off > 27B-off；27B-xhigh ≥ 122B-off（思考把 27B 抬上去），但每题耗时 3–5 倍。27B-low 介于中间。把握：中。
2. **code**：同 1 的排序。把握：中低——HumanEval 上 4bit 量化的 27B 可能撞上限。

4. **tools**：四臂都接近满分（今天的小任务都全对），差别在 token 数：27B-xhigh 每步几百到几千，其余几十。把握：中高。
5. **length 超限**：27B-xhigh 会有几题思考撞 8000；122B-off 零。把握：高。
6. 不预设总胜负；每类各说各的。

### 对 owner 问题的回答："哪个更聪明"
**在这四类题上，122B 不比 27B 聪明。** 同样关思考：数学打平（各 143/150），代码 27B 赢（115 对 109），格式 122B 略好（25 对 23），
工具全对。122B 赢的是**快和省**：每题中位 6 s / 218 token，27B-off 是 9 s / 255。
**最好的配置是 27B + `reasoning_effort: low`**：四类里三类第一或并列，代价每题多三秒。

### 预期对账
1. ✗ "math 122B-off > 27B-off"：打平。"27B-xhigh ≥ 122B-off"：xhigh 最差。
2. ✗ code：27B-off 和 27B-low 都赢 122B-off；xhigh 最差。
3. △ instruct：思考确实帮格式（77% → 97–100%），但最好的是 low 不是 xhigh。
4. ✓ tools 四臂满分；xhigh 每步 token 最多。
5. ✓ 超限：xhigh 20 次，其余 0。

### 共同错的题
没有任何一题被四臂全部答错，也没有任何一题被四臂各错两次以上——失误是模型各自的，不是题库的。
最接近的是 gsm8k-12（柠檬树回本，参考答案 13）：122B-off 三次都答 12，27B-off 一次答 12；题面对"开始赚钱那年"有歧义。
HumanEval-132 被 27B-xhigh 三次超限、122B-off 三次答错，是最难的一题。
122B-off 的失误：数学 7（gsm8k-12 ×3、-675 ×2）、代码 11（-132 ×3、-54 ×3、-108 ×2、-103 ×2）、格式 5（no-letter-e ×3）。

### 条件与边界（下结论前读）
- 一台机器（M3 Ultra 96 GB）、4bit 量化、max_tokens 8000、每题 3 次、模型缺省采样。
- 题目偏易：数学 95% 是天花板效应，分不出更高的差距；HumanEval 只抽 40；格式题 10 条、工具题 5 条是自写的小集。
- "智能"在这里 = 这四类的通过率；长会话、多工具、需要长推理的 agent 任务没测——那正是 122B 可能拉开差距或想太多的地方。
- 122B 只跑了关思考（它的推荐配置）；开思考的 122B 在 MDL-009 里会数数循环，没进臂。
